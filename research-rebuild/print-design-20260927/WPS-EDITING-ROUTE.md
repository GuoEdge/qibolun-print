# 岐伯论：WPS 阅读编辑与编册路线

## 结论

WPS 应成为后续人工阅读、批注、勾画和最终人工调整的主工作环境；HTML design-studio 保留为数据与出版控制台。

## 职责分工

### HTML / Python 控制台

- 读取只读语料；
- 管理分类和分册；
- 生成阅读版 DOCX 输入；
- 生成封面、母版和样式配置；
- 生成总目录和索引草稿；
- 运行内容、图片和版式预检；
- 批量生成专题册；
- 记录版本、哈希和输出 manifest。

### WPS 文字

- 打开并审阅 DOCX；
- 阅读正文；
- 手工批注；
- 勾画、标注和修改版式；
- 调整局部分页；
- 细调图片和图注；
- 修订标题、页眉、页脚和目录；
- 输出最终 PDF 或打印稿。

## 推荐输出结构

第一阶段不要生成一个包含 4,303 篇文章的超大 DOCX。建议：

- 先生成一册完整样书 DOCX；
- 再按专题/分册生成 32 个 DOCX；
- 总目录和全书索引单独生成一个 DOCX；
- 附录生成独立 DOCX；
- 需要时再合并，不以合并大文件作为唯一工作文件。

## DOCX 模板层

生成器应建立以下样式：

- `QBL-CoverTitle`：封面书名；
- `QBL-VolumeTitle`：专题册名和卷次；
- `QBL-FrontMatter`：扉页、版本说明和本册说明；
- `QBL-TOC`：目录；
- `QBL-ArticleTitle`：文章标题；
- `QBL-ArticleDate`：发表日期；
- `QBL-Question`：原始提问；
- `QBL-Body`：正文；
- `QBL-ImageCaption`：图片说明；
- `QBL-ResearchMeta`：篇末来源与分类信息；
- `QBL-Notes`：研究笔记；
- `QBL-Index`：索引；
- `QBL-Header` / `QBL-Footer`：页眉页脚。

## WPS 中建议保留的可编辑对象

- 正文段落；
- 提问段落；
- 图片对象；
- 图注；
- 篇末研究信息；
- 批注；
- 页眉页脚；
- 目录域；
- 索引条目；
- 封面方印图片或形状。

## 方印处理建议

HTML 设计台只负责生成方印方案和方印素材；WPS 中保留为独立图片或形状对象，以便：

- 拖动位置；
- 改变大小；
- 旋转；
- 调整透明度；
- 替换字体或重新导出方印；
- 在封面、扉页和正文母版中分别决定是否显示。

不建议把方印烙死在正文背景中。

## 字体处理

字体以 WPS 本机实际可用字体为准。生成器不应假设浏览器字体列表就是 WPS 字体列表。

建议流程：

1. WPS 中确认本机字体；
2. 生成器使用字体名称写入 DOCX 样式；
3. 打开 WPS 后检查字体替换提示；
4. 若字体不存在，使用备用字体；
5. 最终 PDF 导出前检查字体嵌入或替换情况。

推荐配置字段：

```json
{
  "font": {
    "body": "本机确认的字体名",
    "heading": "本机确认的字体名",
    "seal": "本机确认的字体名",
    "fallbackBody": ["宋体", "Noto Serif CJK SC", "serif"]
  }
}
```

## 批注和勾画

WPS 版本需要确认批注与审阅功能入口。原则上：

- 正文版 DOCX 允许用户直接批注；
- 生成器不把研究信息转成不可编辑图片；
- 篇末保留空白或笔记线；
- 页边保留装订和外侧批注空间；
- 图片不锁死在页面背景；
- 目录和索引尽量使用可更新域，而非纯文本。

## 生产闭环

```text
只读语料/分类
  → Python 生成阅读版 DOCX
  → WPS 人工阅读、批注、局部排版
  → WPS 保存审阅版
  → Python/人工记录修订决定
  → WPS 更新目录、页眉页脚、索引
  → 导出 PDF
  → 最终预检
```

## 关键风险

- WPS 版本差异会影响菜单、样式、目录域和 PDF 导出；
- 超大 DOCX 可能变慢或损坏；
- WPS 重新分页后，目录和索引页码必须更新；
- 字体替换可能导致页数变化；
- 图片过多的专题需要单独样书验证；
- HTML 预览页数不能直接等同 WPS 最终页数。

## 推荐下一步

1. 暂停继续堆 HTML 自由排版功能；
2. 做一个 WPS 可打开的完整样册 DOCX；
3. 用样册验证字体、批注、图片、目录和方印；
4. 根据 WPS 实际效果调整 DOCX 模板；
5. 再批量生成 31 个专题册和附录册；
6. 最终以 WPS 审阅版和 PDF 为交付对象。
