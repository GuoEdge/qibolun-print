# 岐伯论阅读正文版编册规范

版本：2026-09-27
适用输入：`print-20260926-rebuilt-v2` 及其对应分类索引

## 1. 编辑目标

本版不是研究字段的完整档案表，而是用于连续阅读、研究学习、批注和勾画的阅读正文版。

核心优先级：

1. 正文连续、清楚、少打断。
2. 纸面有足够的批注和勾画空间。
3. 每篇文章仍可回溯到原文和分类位置。
4. 分册厚度相近，避免过厚或过薄。
5. 目录和索引能够支持后续查找与比较。

## 2. 单篇文章模板

每篇文章按以下顺序排印：

### 文章正文区

1. 文章标题
2. 发表日期（小号常规字，可放标题下）
3. 原始提问
4. 正文全文
5. 文章图片（按正文关联顺序，必要时附简短图注）
6. 篇末研究信息（小号字）

正文区不显示以下字段：

- 数据库 UUID / 源 ID
- 原文完整 URL（改用二维码）
- 官方对象—实践路径的长字段
- 未经独立通读复核的 23 概念标签
- DeepSeek 初读状态
- 独立复核状态
- 候选分数和分类规则 ID

这些内容只在篇末研究信息、分册索引或总档案中保留。

### 篇末研究信息

篇末用 8.5–9.5pt 小字，和正文形成明显的视觉层级，内容按以下顺序：

- 原文入口：二维码 + 四位文章短号，必要时附短码；不直接印长 URL；
- 主专题：名称；
- 副专题：仅列名称；
- 官方路径：保留对象—实践路径的简写；
- 23 概念：保留概念名称，不显示内部字段名；
- 状态标记：只在需要时显示“待审”“正文缺失片段”“图片源不完整”等异常状态。

篇末研究信息与下一篇文章之间至少保留一个明显的段落间隔，避免和正文混淆。

## 3. 批注空间

批注空间是本版的正式功能，不是排版剩余空间。

- 正文版心不宜过宽，左右页边应保留稳定外侧空间；
- 内侧装订边比外侧更宽，避免装订后难以书写；
- 文章之间保留明确的起止边界；
- 每篇文章篇末至少保留 1/4 页空白，短文可保留 1/2 页；
- 长文不强行增加空白，但在每个分册中设置若干“研究笔记页”；
- 研究笔记页按分册设置，不按每篇机械插入；
- 图片不得占满整页后完全取消书写空间，除非图片本身是研究对象；
- 目录、索引和附录页也应保留适度边距，不采用满版密集表格。

建议纸张版心：

- 根据 A5 样章与实际打印体验，本版改用 A4 纵向；
- A4 版心不满版，保留稳定外侧批注区和内侧装订边；
- 具体字号、行距、页边距和图片宽度通过 A4 样章实测确定，不以 Markdown 页数直接等同最终页数。

## 4. 图片规则

- 图片只保留已视觉复核且审读结论允许排印的图片；
- 图片放在关联正文之后；
- 多图按原文顺序排列；
- 图片下方使用短图注，不重复大段审计说明；
- 图片源缺失时只保留“图片源不完整”标记，不用邻近图片替代；
- 图片与正文无关时不进入阅读版，但在档案中保留决定；
- 图片密集专题应单独增加图片版面预算。

## 5. 分册厚度

不再把 200 页视为硬上限。200 页只是当前初始切分参考。

分册平衡采用“文字页数 + 图片负担 + 文章数量”三项综合估算：

- 普通文字页：按正文字符估算；
- 图片页：按图片数量、尺寸和图注估算额外版面；
- 文章数量：防止某册文章极多、每篇过短导致查阅体验差；
- 同一专题尽量保持连续日期顺序，不为追求页数完全平均而打散时间序列；
- 允许相邻分册相差约 10%–15%；
- 超过 200 页少量不构成问题，但应避免出现明显的 100 页以下薄册与 250 页以上厚册并存；
- A14、A17、A19、A21 等小专题保持独立，不为均厚强行合并。

## 6. 目录设计

每册至少包含：

1. 册名页；
2. 本册说明；
3. 本册目录；
4. 正文；
5. 本册研究笔记页；
6. 本册文章索引。

本册目录字段：

- 文章标题；
- 发表日期；
- 源序号；
- 起始页码（正式 PDF/DOCX 排版后生成）。

总目录应包含：

- 全部专题册；
- 每个专题的文章数；
- 每册日期范围；
- 估算页数或最终页数；
- 附录册说明。

## 7. 索引设计

索引分为稳定定位索引和研究交叉索引。

### 稳定定位索引

- 源序号 → 标题、日期、专题、册号、页码；
- 标题 → 源序号、专题、册号、页码；
- 日期 → 文章列表。

### 研究交叉索引

- 主专题索引；
- 副专题索引；
- 官方对象—实践路径索引；
- 23 概念索引；
- 图片文章索引；
- 异常状态索引；
- 附录文章索引。

索引中的页码必须在最终分页后生成，不能从 Markdown 估算页数直接代替。

## 8. 附录

附录为研究档案册，不作为正常专题阅读正文。

附录收录：

- 待审文章；
- 排除候选；
- 正文过薄或正文缺失文章；
- 图片与正文关系异常文章；
- 源材料不完整文章。

附录每篇仍保留提问、正文、图片决定和状态说明，但在册首明确说明：

> 本册用于保存研究档案，不代表其中文章已经完成专题确认，也不代表内容适合进入正文阅读体系。

## 9. 输出顺序

1. 先生成单篇模板；
2. 选择短文、长文、含图文和异常文章生成样章；
3. 确定开本、字号、行距、边距和图片宽度；
4. 批量生成阅读正文版；
5. 生成总目录和分册目录；
6. 生成最终页码索引；
7. 输出 PDF/DOCX；
8. 抽查长册、图片密集册、短专题和附录册。
