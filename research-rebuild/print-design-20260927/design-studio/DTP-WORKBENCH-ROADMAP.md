# 岐伯论 DTP 编册工作台路线

## 定位

design-studio 不再只是单篇文章预览器，而是面向《岐伯论》长文档编册的本地 DTP 工作台。目标是向 InDesign 的核心出版工作流看齐，同时保留本地、可追溯、数据只读和适合研究工作本的特点。

不追求复制 InDesign 的全部通用能力，而是优先实现本项目真正需要的出版能力，并保持配置可导出、可复现、可批量编册。

## 工作台模块

### 1. 文档与出版设置

- 文档尺寸：A5、B5、A4、自定义；
- 页面方向；
- 对页/单页；
- 装订方式；
- 内外边距、出血、装订增量；
- 页面网格、基线网格、参考线；
- 纸张、黑白/彩色和印刷预设；
- 版本和数据哈希绑定。

### 2. 页面与母版

- 母版页：正文、章节首页、图片页、附录、目录、索引、笔记页；
- 母版对象：页眉、页脚、书口、页码、版框、装饰、批注栏；
- 左右对页独立设置；
- 页面应用母版；
- 页面局部覆盖；
- 页面插入、删除、复制和重排；
- 母版锁定，防止批量编册时误改。

### 3. 文本与样式

- 段落样式：标题、日期、提问、正文、引用、图注、篇末研究信息、笔记标题；
- 字符样式：强调、链接、状态、概念标签、源序号；
- 样式继承、覆盖和恢复；
- 字体、字号、字重、行距、字距、缩进、段前段后；
- 中西文混排、标点挤压、孤行/寡行控制；
- 文章前后自动样式；
- 样式批量替换。

### 4. 对象与资产

- 图片框、文字框、图注框、研究信息框、笔记框；
- 对象位置、宽高、旋转、裁切、边框、填充、透明度；
- 图片比例锁定；
- 图片版式预设：单图、双图、连续图、整页图；
- 图片资产列表、状态、分辨率、缺失和审计结论；
- 文章与图片关联；
- 图片不替代正文证据。

### 5. 长文档与分册

- 文章顺序和分册切点；
- 章节/专题；
- 自动分册与手工锁定；
- 长文分页与跨页控制；
- 文章不拆、标题跟随正文、图片不孤立；
- 批注页、目录页、索引页和空白页计入分册；
- 文章密度、长短文比例、图片负担、批注负担综合平衡。

### 6. 目录、索引和交叉引用

- 总目录、专题目录、分册目录；
- 源序号、标题、日期、主专题、副专题；
- 官方路径、23 概念、图片、异常状态索引；
- 文章交叉引用；
- 目录/索引自动更新；
- 页码两遍编译回填；
- 交叉索引只重复指向，不重复排印正文。

### 7. 预检与校样

- 内容完整性；
- 页面溢出；
- 图片分辨率；
- 字体缺失；
- 标题孤页；
- 提问与正文分离；
- 图片过小或越界；
- 批注空间不足；
- 页数和折页；
- 目录索引失效；
- 黑白打印对比度；
- 输出前错误列表和定位。

### 8. 版本与导出

- 设计方案保存、复制、比较、回退；
- 方案锁定；
- 配置和语料哈希；
- 导出 design-config.json；
- 导出样章 HTML；
- 导出无页码目录索引；
- 批量编册输入；
- HTML/PDF/DOCX 生产链路预留。

## 初版优先级

第一批直接进入工作台：

1. 页面设置和出版预设；
2. 段落样式和字符样式；
3. 母版页和页眉页脚；
4. 文章/图片/篇末信息对象控制；
5. 预检面板；
6. 方案版本和导出配置；
7. 分册基线与目录索引。

第二批：

- 页面缩略图和页面重排；
- 母版应用和局部覆盖；
- 文章分页模拟；
- 综合分册平衡；
- 图片框拖拽和裁切；
- 目录/索引两遍编译。

第三批：

- 完整样册编译器；
- PDF/DOCX 输出；
- 印刷预检报告；
- 全量 32 册生产。

## 与 InDesign 的对应关系

| 出版能力 | design-studio 对应模块 |
|---|---|
| 文档设置 | 页面与出版设置 |
| Parent/Master Pages | 母版页 |
| Paragraph/Character Styles | 段落样式/字符样式 |
| Text Frames/Object Styles | 文章对象/图片对象/研究信息对象 |
| Book/Sections | 专题、分册和章节 |
| TOC/Index | 目录索引构建器 |
| Preflight | 内容/版式/印刷预检 |
| Package/Export | design-config 和批量编册输出 |
| Links/Assets | 图片资产与审计状态 |
| Story Editor | 文章正文预览与结构化字段 |

## 设计台原则

- 所有参数都有当前值、默认值、重置和导出；
- 所有对象都能定位到文章、源序号或页面；
- 所有批量能力都可回溯到原始语料；
- 设计修改不修改原文、不改分类、不删除图片；
- 默认提供可靠预设，但不限制个性化设计；
- 先完成一册完整样书，再启动全量编册。
