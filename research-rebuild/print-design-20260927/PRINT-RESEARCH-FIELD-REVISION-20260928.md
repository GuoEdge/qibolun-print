# 阅读研究版纸质字段修订方案

版本：2026-09-28
原因：A5 样章与实际印刷体验显示页面过紧；源 ID 对纸质阅读价值低；原文链接需要改为二维码；23 概念标签当前不宜直接作为正文纸面标签。

## 一、版式改为 A4

### 已决定

- 阅读研究版由 A5 改为 **A4 纵向**；
- 正文、图片和批注空间全部以 A4 双面打印实测为准；
- 仍保留较宽内侧装订边和外侧批注区，不因为 A4 变宽就把正文撑满整页；
- 图片优先利用 A4 的版心宽度，但研究性图片仍按可辨识度和书写空间平衡；
- 册数重新估算，不能把 A5 方案按比例直接换算。

### A4 的功能优势

- 长提问、原文段落和篇末研究信息不必过度折行；
- 图片可在不压缩到不可读的情况下放入正文；
- 外侧批注栏和内侧装订边可以同时保留；
- 目录、索引和二维码有足够宽度；
- 双面打印后更适合桌面阅读和研究性批注。

### A4 的注意点

- 不能因为版面变大就把行长拉到杂志/报纸式过宽；
- 版心应控制在适合中文连续阅读的宽度，外侧剩余空间正式划为批注区；
- 需要重新实测字号、行距、每页行数、图片最大宽高和装订边；
- A4 纸张和成品册重量会增加，分册目标应同时考虑重量、开合和打印成本。

## 二、纸质版隐藏数据库字段

以下字段仍保留在 CSV/JSON、总导航册或后台索引中，但默认不进入每篇纸质正文：

- 内部 `id` / UUID；
- 数据库用源 ID；
- 分类规则 ID；
- 机器候选分数；
- DeepSeek 可用性和内部复核字段；
- 不适合读者直接使用的状态字段。

### 纸质版保留的稳定识别方式

- 篇题保留四位源序号作为纸面短号，例如 `2967`；
- 篇题保留文章标题；
- 目录和纸质索引使用“源序号 + 标题 + 日期 + 册号 + 页码”；
- 不在篇末再重复打印 UUID 或“源 ID”字段。

四位序号是读者可见的纸面引用号；内部 UUID 继续只在数据库和档案中使用。

## 三、原文入口从文字链接改为二维码

### 每篇篇末建议结构

二维码放在篇末研究信息的最右侧或单独的小二维码单元，旁边只保留：

- `原文入口`；
- 文章短号（四位源序号）；
- 可选短码/域名文字，防止二维码损坏后完全无法定位。

不再把长 URL 直接印成正文小字。纸面二维码下方必须有足够空白，避免与批注线和下篇标题混淆。

### 二维码规则

- 二维码内容为原文链接；
- 黑白打印可识别，不能使用低对比度朱色二维码；
- 最小尺寸需用实际 A4 黑白打印和手机扫码测试确定；
- 每个二维码生成时记录 URL、源序号、生成版本和校验值；
- 原文链接失效时，二维码仍应优先指向可维护的中间跳转页，而不是不可更改的临时地址；
- 生成二维码后做图片解码抽检，不只检查图片文件存在。

二维码是纸质版“回到原文”的入口，不替代源序号、标题和索引。

## 四、23 概念层暂不作为正文印刷标签

### 当前判断

23 概念保留为后台研究候选层和未来索引重建对象，暂时从普通文章的篇末研究信息中移除。

原因：

1. 当前概念字段有完整值，但概念独立复核不足；
2. `evidence_basis` 中 `23_concept_route` 出现于 4305 篇中的 4262 篇，显示概念路由被广泛用作分类依据；
3. `theme_audit_status` 仍有 169 篇 `review_required`、62 篇 `needs_human_classification`；
4. `independent_review_status` 有 4271 篇仍为 `not_reviewed`；
5. `concept_primary` 极度集中：事实与证据 1507、定义与达意 1112、能力与学习 957，前三项合计 3576 篇，约占 83.1%；
6. 这更像宽口径的机械路由/候选召回结果，而不是已经通过逐篇通读界定的成熟概念索引；
7. 概念名称本身带有理论解释色彩，若没有文章段落证据，印在正文后会制造“作者明确在讨论该概念”的误读。

### 处理方式

- 纸质阅读版：默认不显示 23 概念标签；
- 全书导航/研究索引：先标为“候选概念索引”，不写成定论；
- 数据字段：保留原值，新增 `concept_display_status`，不覆盖原始分类结果；
- 未来重建：必须先定义每个概念的正例、反例、边界和证据要求，再做分层抽样通读；
- 只有通过人工复核的概念关系，才允许进入“已核验概念索引”；
- 文章可能有多个概念，但不能为了凑标签而强行给每篇分配主概念。

### 未来概念复核标准

每个概念至少要有：

- 一句话操作性定义；
- 纳入条件；
- 排除条件；
- 正例与反例；
- 文章正文或提问中的证据摘录；
- 与相近概念的区分；
- `confirmed / candidate / rejected / not_reviewed` 状态。

没有这些条件时，概念层只应是研究候选，不应承担纸质导航功能。

## 五、修订后的篇末信息

普通正文篇末默认只保留：

1. 四位源序号（文章短号）；
2. 原文二维码；
3. 发表日期；
4. 主专题；
5. 必要时的副专题/官方路径简写；
6. 仅在有问题时显示异常状态。

概念标签、UUID、内部规则和长 URL移入后台/导航册。

建议视觉顺序：

```text
篇末研究信息
[原文二维码]  2967  日期 2021-11-02
主专题：A21 体育、运动与竞技伦理
副专题：A15　路径：与社会 / 与文化 / 接纳
异常：无
```

篇末信息应短、可扫、可回查，不再像数据库字段倾倒。

## 六、对文章编排和纸面审美的影响

- A4 让文章标题、提问、正文和研究信息形成更完整的版面闭合；
- 二维码替代长 URL 后，篇末小字层可以明显减轻；
- 去掉概念标签后，正文结束处不再被一串抽象术语打断；
- 去掉 UUID 后，纸面不再出现与阅读无关的技术噪音；
- 页边空白、短笔记区和二维码之间要有明确分层；
- 纸质版变成“可读的研究工作本”，数据库和完整索引另行承担机器定位任务。

## 七、下一步

1. 将 Node DOCX 生成器默认页面改为 A4；
2. 生成二维码并做黑白打印扫码样张；
3. 从普通篇末信息中隐藏 UUID、长 URL 和 23 概念标签；
4. 做 A4 的短文、长文、图密、附录四类样章；
5. 重新实测页数与分册，不沿用 A5/52 册方案；
6. 另行设计“概念候选索引”或暂时不印概念索引；
7. 等用户确认 A4 样章后，再重新计算全书分册。
