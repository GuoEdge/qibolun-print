# 全文通读写主旨规范（庚册、壬册以外 41 个编码）

输入：`units/rest_full/Rxx.md`。每篇以 `=== 【序号】标题　〔册号·单元名〕` 开头，下接「問：」与「答：」全文。
输出：`units/rest_full_out/Rxx.json`：

```json
{"chunk":"R01","items":{"3":{"gist":"……","fit":1}, "8":{"gist":"……","fit":0,"note":"……"}}}
```

序号用字符串，块内每篇都必须有。

## 要求
1. 必须用 Read 工具分段（offset/limit）把整个 md 读到末尾，逐篇读完「答」全文。不能只看标题、问题或开头。
2. gist：简体中文 15–30 字，写正文实际在讲什么、落点在哪。不要复述问题。示例：「借俄乌传闻讲如何验证消息来源，重在信息甄别」。
3. fit：本篇正文与所在单元名（〔〕中所注）是否相符。相符或大体相符写 1；明显不符写 0，并在 note 里用不超过 20 字说明它实际该属哪类主题。fit 宜宽，只有确实离题才写 0。
4. 只写 JSON，不要在 units 目录留下其他文件。/tmp 是只读的，自检用 `/data/service/hnp/bin/python3 -c` 内联执行。shell 的 getcwd 会报错，一律用绝对路径。
5. 自检：键集合与 md 中全部【序号】一致，gist 均不为空，fit 只取 0 或 1。
6. 回报：每块篇数、fit=0 的序号及 note。不必复述 gist。
