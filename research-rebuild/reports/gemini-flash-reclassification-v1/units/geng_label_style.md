# 庚册逐篇归属判定规范

输入：`units/geng_in/{CODE}.tsv`，每行为 `序号\t标题\t问题\t正文摘要`。
输出：`units/geng_out/{CODE}.json`，格式为 `{"code":"B38A","labels":{"序号":"类别码", ...}}`。序号用字符串，每一篇都要有标签。

类别码（每篇只选一个，以“问题”为主要依据，标题常是隐喻，不要单看标题）：

- S 时局：具体的时事、国际关系、大国博弈、战争军事、宏观经济与产业政策（芯片、汇率、制造业、能源、基建）、国家治理与法政制度、重大公共事件、民族与国家认同。这类篇目将移到卷六“時局經緯與家國論衡”。
- X 修心：自我认知、情绪、意志、心性修养、独处、人生选择、个人成长、焦虑与自救。
- R 处世：人际分寸、交往应对、识人、职场与谋生、名声面子、如何回应他人、团队。
- Q 家室：恋爱、婚姻、亲子教育、孝养、家庭关系。
- G 格物：自然科学、技术原理、技艺手艺、生活实务、饮食器物、艺术影视文学、体育游戏。
- Y 世情：人性善恶、道德义理、寓言杂谈、历史文化人物评说（不涉当代时政）、社会风气与世相（非具体政策或时事）。

判定要点：
1. S 要从严。只有“问题”本身指向具体时事、国家或国际议题、政策、产业或战争的才标 S。借时事讲做人道理的，按道理归类。
2. 社会风气、网络心态、人性评论这类，若没有具体政策或国家议题，标 Y。
3. 历史人物或古代战争，若只是论成败或谋略、不涉当代国际时局，标 Y。
4. 只写 JSON 文件，不要在 units 目录下留下任何临时脚本。需要脚本时，放到 /tmp/ 下并用唯一文件名。
5. 写完后自检：标签数等于 tsv 行数，类别码只用 SXRQGY 六个。
