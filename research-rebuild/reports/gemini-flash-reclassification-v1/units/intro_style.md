# 单元导语重写规范

用途：每个单元开篇的扉叶居中印一段导语（宋刻体 12pt，约 22 字一行）。读者翻到这里，要能一眼知道本单元讲什么、核心看点在哪。

## 要求
1. 繁体中文，半文言、雅正简洁，像古籍篇首小序。不要白话口水，也不要堆砌生僻字、强行用典。
2. 不得以“收”字开头，正文里也不要用“收”字（扉叶底行已有“本單元收文 N 篇”）。
3. 开头要多变，全书不能千篇一律。可选句式（仅供参考，自行变化）：
   - “此單元論……”“是編所輯，……”“凡……之問，……”“言……”“論……”“……者，……也。”
   - 直接以议题起笔：“父母之愛，易成羈絆；……”
4. 结构：两句为宜。
   - 第一句点出本单元的核心主题或立意（概括，不是罗列）；
   - 第二句点出所涉的具体议题或看点（可列举 3–4 个最有代表性的面向），让读者知道里面有什么。
5. 长度 36–72 个汉字（含标点）。以句号结尾。
6. 必须忠实于该单元实际所收篇目（看清单里的标题/问题/摘要），不要编造篇目里没有的内容。
7. 不出现具体人名、时间、敏感政治表述；时政类单元用“時局”“世變”“列國”“公共事件”等概括即可。
8. 不要用“本單元”三字（底行已有），可用“此編”“是編”“此單元”或不用指代。

## 示例
旧：收焦慮內耗、委屈憋悶、情緒控制與獨處自省等日常心緒之問。
新：心緒之亂，多起於內耗與委屈。此編論焦慮何以自擾、怨氣何以自消，兼及獨處自省、調伏情緒之法。

旧：收股市投資、負債儲蓄、家庭財富與財務規劃的問題。
新：錢財之事，貴在知所進退。是編論股市沉浮、負債儲蓄與家計規劃，辨明守財與生財之道。

## 输出格式
每册写一个 JSON 文件到 `units/intro_out/{CODE}.json`：
```json
{"code": "B01", "intros": {"生養抉擇": "……。", "居家防患": "……。"}}
```
键必须与输入里的单元名逐字一致（繁体），每个单元都要有。
