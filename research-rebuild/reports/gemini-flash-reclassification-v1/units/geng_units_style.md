# 庚册重组：分册排单元规范

## 输入
- `units/geng_units_in/{TAG}.tsv`：本类全部篇目，列为「序号 / 字数 / 标题 / 问题 / 正文主旨」。正文主旨是通读全文后写的，可以信赖。
- `units/geng_units_in/_used_names.txt`：其他册已经用掉的单元名，新单元名不得与其中任何一个重复。
- `units/intro_style.md`：导语文风规范，必须先读，严格遵守。

## 任务
把本类全部篇目分成上、下两册，每册各排若干单元。

1. 先通览全部篇目，按主题归纳出 8–12 个单元。每个单元主题集中、互不交叉，单元内至少 5 篇。
2. 把单元分给上、下两册：上册放前一组单元，下册放后一组。每册 4–6 个单元。两册的总字数（按字数列求和）要接近，相差不超过 15%。同一主题不要拆到两册去。
3. 单元的先后顺序要有内在理路，比如由内到外、由浅入深、由己及人。
4. 单元名：繁体四字，雅正凝练，例如「安頓自心」「識人知微」。不得与 `_used_names.txt` 重复，同类两册之间也不得重复。为避免与其他组撞名，名中尽量带本类特色字。
5. 导语：按 intro_style.md 写，繁体半文言，两句，36–72 字，以「。」结尾，不含「收」字和「本單元」。第一句点出单元主旨，第二句列出 3–4 个代表性议题。依据正文主旨来写，要准确概括本单元实际所收篇目。
6. 本类每一篇都必须恰好出现一次，不得遗漏，不得重复。

## 输出
写入 `units/geng_units_out/{TAG}.json`：

```json
{"tag":"X","books":[
  {"code":"B38A","units":[{"name":"安頓自心","intro":"……。","ordinals":[3,8]}]},
  {"code":"B38B","units":[...]}
]}
```

ordinals 用整数，升序排列。

## 自检
用 `/data/service/hnp/bin/python3 -c` 内联运行（/tmp 只读，units 目录下不得留下任何其他文件；shell 的 getcwd 会报错，一律用绝对路径），逐项确认：
- 序号全集与 tsv 完全一致，无漏无重；
- 每册 4–6 个单元，每个单元不少于 5 篇；
- 两册字数差不超过 15%；
- 单元名为四字，不在 _used_names 中，本文件内不重复；
- 导语 36–72 字，以「。」结尾，不含「收」和「本單元」，没有简体字。

## 回报
每册的单元名、篇数、字数，以及每条导语。
