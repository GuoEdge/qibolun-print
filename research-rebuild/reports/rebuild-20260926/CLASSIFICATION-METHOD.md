# 分类方法与依据（2026-09-26 版）

本文回答三件事：**分几层**、**按什么顺序判**、**每篇实际怎么做的**，以及**什么情况才允许留在待审**。
所有条目都可以按第八节的路径逐篇回溯到原文。

---

## 一、四层结构：一篇文章同时有四个身份

| 层 | 字段 | 取值 | 用途 | 谁说了算 |
|---|---|---|---|---|
| **A 打印主专题** | `primary_print_topic` / `primary_print_topic_code` | A00–A21 中**恰好一个** | 决定这篇文章印进哪本册子、只印一次 | 人工决定（本轮由正文复核产出） |
| **B 打印副专题** | `secondary_print_topics` | 0–3 个 | 跨专题检索的交叉入口 | 人工决定，**必须有正文支持** |
| **C 官方对象—实践路径** | `native_object_paths` / `native_practice_paths` | 0–N 个 | 保留素问官方"和谁/什么对象、做什么实践"的原意 | 官方快照，**不得伪造** |
| **D 23 概念标签** | `concept_tags` | 0–23 个 | 跨对象比较（同一问题出现在家庭/职场/国家） | 旧研究复用 + 候选，用于检索 |

四层各记各的状态，互不背书。一篇文章**只能有一个 A**，这是印刷不重复的硬约束。

---

## 二、判定依据的优先级（谁压倒谁）

判 A 的时候，证据按这个顺序看，**后面的不能推翻前面的**：

1. **正文里作者实际要回答的中心问题或行动场景** ← 唯一决定性依据
2. 官方对象—实践路径指向的主要关系对象（辅助确认对象是谁）
3. 正文中**连续展开**的证据域（不是出现过的词）
4. 标题、题面、旧研究路由、机器候选 ← **只作辅助，不得凌驾正文**

几条由此推出的硬规则：

- **标题和题面不能替代正文**。题面是"在女性面前开黄色玩笑"，但正文第一段就把议题去性别化并转入"冒犯试探与义人托付"，所以这篇文章的主码是 A07（组织与合作），不是 A02（性别身体）。
- **关键词计数不算分类**。A03 不是"出现'证据'二字最多的文章"。
- **比喻不算领域**。《厨房清洁策略》结尾"良医治其未病"是比喻，不能据此把 A09（医疗）挂上去。
- **审核者附加的邻近领域联想要删**。这类副码是本轮删得最多的一类（共 54 处副码修订）。

## 三、每篇实际执行的动作（同一套流程，92+28+79 篇都走了一遍）

1. **读完整正文**，并记录阅读覆盖（`full_text` 或 `head1000+tail500`）。长文分段读完，不读开头就下结论。
2. **找中心操作**：这篇文字**实际干了什么**——给定义？做区分？给方案？下判断？讲机制？
3. **定唯一主码**：这个中心操作落在 A00–A21 的哪一格。
4. **副码只留正文支持的**，0–3 个，主码不得出现在副码里。
5. **抄一句逐字原文**作为依据（`body_evidence_quote`）——不是转述，是原文片段。
6. **机械校验**这句原文确实在该篇正文里（去空白后 ≥12 字连续命中）。
7. **写清状态、阻塞原因、审核日期、审核人**。

## 四、两层状态：什么是"确认"，什么是"待审"

### `manual_confirmed`（确认）

同时满足四条才给：

- (a) 正文包含**作者自己的**中心处理——不是题面复述、不是裸引文、不是外链标题、不是检索指引、不是截断残句；
- (b) 该处理能把主专题**唯一**定到 A00–A21 中的一格；
- (c) 正文依据以**逐字引文**写入决定行并通过机械命中校验；
- (d) 完成了第二次全文复核。

### `manual_provisional`（待审）

只允许 7 个**材料性**原因：

| 阻塞原因 | 含义 |
|---|---|
| `source_empty` | 正文为空 |
| `source_truncated` | 正文在句中截断 |
| `body_is_quotation` | 正文全是他人的文本（如经文引文） |
| `body_is_pointer` | 正文指向他处（外链标题、检索指引） |
| `body_question_mismatch` | 正文与题面明显不匹配 |
| `body_too_short_for_center` | 正文过短，且不是题面所要的交付物 |
| `a00_registry_gap` | 中心可辨但现有专题表确无入口 |

### **明令禁止**用来保持待审的理由

框架第五节写着"**不得仅因事实主张未核验而使用临时状态**"。因此下面这些**不能**当待审理由，只能写进风险注记：

- "作者的医学/技术/法律/历史/军事判断未外部核验"；
- "引文出处、译本未核验"；
- "作者用了'怀疑''很可能'等措辞"；
- "图片还没审完"（图片审计与主题分类是两个独立决定）。

> 这正是本轮能把 92 篇里 80 篇升级的原因：它们的历史待审理由绝大多数是上面这四类，
> 属于事实核验层，不是专题判定层的阻塞条件。

## 五、本轮新增的判定线（R1–R5，已单独落盘）

| 编号 | 内容 |
|---|---|
| **R1** | 暂定→确认的四条件（见第四节） |
| **R2** | 只有 7 个合法阻塞原因；四类"事实未核验"理由被禁止 |
| **R3** | 正文 < 20 字且非交付物 → `body_too_short_for_center`，保持待审 |
| **R4** | **A11 的边界含"世俗论证"**：非宗教的规范性人生论证归 A11；A00 不再当"人生价值/伦理"类文章的默认桶，且留在 A00 的必须保持待审 |
| **R5** | **极短回答裁决**：正文经核实是作者的完整回答，且**本身就是题面所要的交付物**（示例句、定义、判断、话术），则可确认；若正文只是**指向他处**、是**他人文本**、**截断**、**空**或**与题面不符**，则保持待审 |

## 六、"待续/未完"怎么处理（按你的指令核对结果）

**带「（未完，待续）」标记的文章不作为待审理由，全部已审核并收进对应专题册。**

| 核对项 | 结果 |
|---|---|
| 正文自带「未完/待续」标记 | **50 篇** |
| 其中进入专题正册 | **50 篇（100%）**，分布在 A01/A02/A03/A04/A05/A06/A07/A08/A11/A12/A13/A16/A19/A20 |
| 因"未完"而保持待审 | **0 篇** |
| 剩余 7 篇待审中含未完标记 | **0 篇** |

处理方式：确认主题、收录进册，同时在册内标 `【正文标注未完待续】`，并在风险注记写明
"本确认只覆盖现有可见正文，不追认未发表部分"。

> 与"未完"要区分的是**截断**：`没伦理`（"如果没有伦理道德，厂"）不是作者的未完标记，
> 而是抓取到的正文在词中间断掉，无法补全，因此仍待审。

## 七、机械校验与反造假（每轮都跑，结果写进各轮报告）

| 校验 | 要求 |
|---|---|
| 引文原文命中 | 逐字引文去空白后 ≥12 字连续片段必须在该篇正文中命中 |
| 代码合法性 | 主/副码必须都在注册表 A00–A21 内 |
| 主副互斥 | 主码不得出现在副码 |
| 唯一性 | 每篇恰好 1 个主码，副码 0–3 个 |
| 集合一致 | 选择清单 / 正文包 / 决定表 / 审计表行数与 ID 集合完全相等 |
| 状态合法 | 待审行必须填 7 个合法阻塞原因之一 |
| 结构验证 | `validate_print_topic_structure_v2.py` → `pass: true`, `errors: []` |

**明确不做的**：不编造审核人/日期；不补造 Round161–164 缺失的决策 TSV；
不为官方未命中的 616 篇伪造官方路径；不把结构 PASS 写成语义完成。

## 八、怎么核查任意一篇（追溯路径）

```
印刷索引 print-research-index.csv
  └─ 一行 → primary_print_topic / classification_status / primary_topic_note
       └─ 该篇所属轮次目录 roundNNN/
            ├─ roundNNN-body-evidence-audit.tsv ← 逐字正文引文 + 决定理由 + 阻塞原因
            ├─ roundNNN-decisions.tsv          ← 主码/副码/状态
            └─ roundNNN-revision-log.csv       ← 改了什么（旧→新）
                 └─ sooon-q9adg-articles-v2.jsonl（只读）← 正文原文，可逐字比对
```

例子：想核《黄色玩笑》为什么是 A07 而不是 A02 →
`round168/round168-body-evidence-audit.tsv` 找到该行 → 看 `body_evidence_quote`
与 `decision_reason` → 回语料正文逐字比对 → 若不服，`round167-168-adjudication-appendix.md`
里记录了这处判断的分歧与我的裁决理由。
