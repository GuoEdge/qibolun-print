## 🔧 鸿蒙 WPS 兼容性修复

本版本实施了 7 项兼容性修复，确保在鸿蒙系统 WPS 上完美显示：

### 1. 留白页物理机制
- **替代方案**：整页无边框 `cantSplit` 表格（14318tw EXACT 行高）
- **废弃方案**：空段落 `pageBreakBefore`（鸿蒙 WPS 行为不一致）

### 2. 目录分叶
- **规则**：26 行/叶，每块 600pt `cantSplit` 外框
- **原因**：防止超页溢出（乙册 101 篇目录 51 行 ≈ 1084pt > 版心 715.9pt）

### 3. 分节符压缩
- **实施**：后处理脚本压缩分节符段落为 1pt exact spacing
- **原因**：防止 `docx` 库自动追加的 ~14pt 空段外溢成幽灵页

### 4. 正文恒起纸正面
- **规则**：目录叶数为奇才补目录背留白
- **目标**：前置物理页数恒为偶数，正文起于奇数物理页（纸正面）

### 5. 表格高度统一
- **参数**：`bodyBudget` 预算系数 1.0（`FRAME_INNER_PT = 586pt`）
- **效果**：所有页块高统一 620pt，外框 600pt atLeast 不扩展

### 6. 二维码朱红色
- **参数**：`qrcode.toFile` 添加 `color: {dark: '#8F2D26', light: '#FFFFFF'}`
- **效果**：所有 QR 码统一朱红色，与印章、题眉同色

### 7. 后处理管线（6 项，不可跳过）
1. 页边距重排：`bottom=1500, footer=600`
2. 关闭网格吸附：`snapToGrid="0"`, `docGrid linePitch="0"`
3. 注入汉字页码格式：`pgNumType fmt="chineseCountingThousand" start="1"`
4. 承接镜像边距与奇偶页眉
5. 固定表格布局（防止 WPS 按文字收缩列宽）
6. 分节符段落压缩（防止外溢成新页）
